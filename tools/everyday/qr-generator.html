QR Code Generator

Type a web address or any text, press Generate and download the QR code as a PNG image. The code is created entirely in your browser, so what you enter is never uploaded.

How to use the QR Code Generator

  1. Enter the text or URL you want to encode.
  2. Pick the error-correction level. Higher levels still scan when slightly damaged but make the code denser.
  3. Press Generate, then Download PNG (or Copy image where your browser supports it).
  4. Test the code with a phone camera before printing it.

Formula and how it works

The QR code is built from your text in UTF-8 using the standard QR Code model 2 specification, with the smallest version that fits your data at the chosen error-correction level. A 4-module blank border (quiet zone) is added, as scanners expect. The tool warns when foreground and background colours have too little contrast to scan reliably.

Capacity is limited: roughly 2,900 characters at Low and about 1,270 at High for plain text. QR Code is a registered trademark of DENSO WAVE INCORPORATED.

Example

Entering https://example.com at Medium correction produces a 25 × 25 module code that any phone camera can open as a link.

Frequently asked questions

Does the QR code expire?

No. This creates a static QR code that simply contains your text. It works as long as the destination (such as your website) works.

Is my text or link sent to a server?

No. The code is drawn in your browser using a small open-source library, and nothing is uploaded.

Which error-correction level should I choose?

Medium suits most uses. Choose High if the code will be printed on rough surfaces or have a logo placed over it.

Why will it not generate?

The text may be too long for a QR code, or the colours may be too similar. Shorten the text or use a dark foreground on a light background.
