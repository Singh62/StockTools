UUID Generator

1 to 1000
Format

Create random version 4 UUIDs (also called GUIDs) for database keys, test data or file names. Generate a single one or a whole batch and copy them in one click.

How to use the UUID Generator

  1. Enter how many UUIDs you need (1 to 1000).
  2. Choose uppercase or hyphen-free output if your system expects it.
  3. Press Generate. One UUID is already generated when the page opens.
  4. Press Copy all to copy every UUID, one per line.

Formula and how it works

A version 4 UUID is 128 bits, of which 122 are random. The remaining 6 bits mark the version (the digit 4) and the variant (the first digit of the fourth group is 8, 9, a or b). The format is xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx.

Random bytes come from the browser's crypto.getRandomValues, a cryptographically secure source. Collisions are astronomically unlikely, but a UUID is an identifier, not a secret: do not use it as a password or access token by itself.

Example

A generated value looks like 3f2b8c1e-9a47-4d6b-8e15-2c7f0a9d4b36. Note the 4 at the start of the third group.

Frequently asked questions

What is the difference between UUID and GUID?

They are effectively the same thing. GUID is the term used mainly in Microsoft ecosystems.

Can two UUIDs ever be the same?

In theory yes, in practice the chance with 122 random bits is negligible, even across billions of values.

Are the UUIDs generated on a server?

No. They are created in your browser and are never sent or stored anywhere.

Is a UUID safe to use as a secret token?

Not by itself. Use a purpose-built token generator for secrets.
