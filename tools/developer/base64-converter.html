Base64 Encoder and Decoder

Convert plain text to Base64 or decode a Base64 string back to readable text. Unicode characters such as Hindi or emoji are handled correctly.

How to use the Base64 Encoder / Decoder

  1. Type or paste text into the input box.
  2. Press Encode to convert it to Base64, or Decode if the input is already Base64.
  3. Tick URL-safe if the result will be used in a URL or JWT-style token.
  4. Copy the output with one click.

Formula and how it works

Base64 represents binary data using 64 printable characters (A–Z, a–z, 0–9, + and /). Every 3 bytes of input become 4 characters, so output is about 33% larger. Text is first converted to UTF-8 bytes, which is why non-English characters work. The URL-safe variant replaces + with - and / with _ and omits = padding. Decoding accepts both variants.

Base64 is encoding, not encryption. Anyone can decode it, so never use it to protect secrets.

Example

Hello encodes to SGVsbG8=, and decoding SGVsbG8= gives back Hello.

Frequently asked questions

Is Base64 secure?

No. It only changes how data is represented. Anyone can decode it, so it must not be used for passwords or secrets.

Why does decoding fail?

The input may contain characters outside the Base64 alphabet, have an impossible length, or decode to binary data that is not valid UTF-8 text, such as an image.

What is URL-safe Base64?

A variant that swaps + and / for - and _ and drops padding so the value can sit safely inside URLs and filenames.

Can I convert files or images?

This tool handles text only. Decoding a Base64 image will report that the data is not text.
