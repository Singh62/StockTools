SQL Formatter

Options

Paste a one-line or messy SQL query and get a readable version with each major clause on its own line.

How to use the SQL Formatter

  1. Paste your SQL query.
  2. Choose indentation and whether keywords are uppercased.
  3. Press Format.
  4. Copy the formatted query.

Formula and how it works

This is a lightweight, dialect-agnostic formatter, not a full SQL parser. It recognises string literals, quoted identifiers and comments (left untouched), uppercases common keywords, starts new lines at clauses such as SELECT, FROM, WHERE, GROUP BY, ORDER BY and JOINs, and puts top-level AND/OR and select-list commas on their own lines. Complex constructs (nested subqueries, vendor-specific syntax, stored procedures) may format imperfectly. It never changes the meaning of identifiers or values, but always review the result before running it.

Example

select a,b from t where x=1 and y in (1,2) order by b becomes a multi-line query with SELECT, FROM, WHERE, AND and ORDER BY each starting a line.

Frequently asked questions

Does it validate my SQL?

No. It only reformats text; it does not check syntax or run anything.

Will it change my data or values?

Strings and quoted identifiers are preserved exactly; only whitespace and keyword case change.

Is my query uploaded?

No. Formatting runs in your browser.
