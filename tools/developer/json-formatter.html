How to use the JSON Formatter & Validator
  1. Paste your JSON into the left editor, or press Example. The status line under it shows whether it is valid and where any error is.
  2. Choose the indentation and, if you like, sort keys alphabetically.
  3. Press Format ▶ to beautify or Compact ▶ to minify into the right editor. Press Ctrl/Cmd + Enter in the left editor to format.
  4. Switch the right side to Tree to expand and collapse nodes. Use ◀ Use output to move the result back, Copy or Download to take it with you.
Formula and how it works
The tool uses your browser's built-in JSON.parse to validate and JSON.stringify to format, so it follows the strict JSON standard (RFC 8259): keys and strings in double quotes, no trailing commas, no comments.
Limitation: JavaScript stores numbers as 64-bit floats, so integers larger than 9,007,199,254,740,991 can lose precision when re-serialised. Keep such IDs as strings.
Example
Input {"name":"Asha","skills":["js","css"],"active":true} becomes an indented, readable object when formatted, or stays on one line when minified. {"a":1,} is reported as invalid because of the trailing comma.
Frequently asked questions
Is my JSON uploaded to a server?
No. Parsing and formatting happen in your browser. Nothing you paste leaves your device.
Why does it say my JSON is invalid?
Common causes are single quotes, unquoted keys, trailing commas, comments and missing brackets. JSON is stricter than JavaScript object syntax. The message shows where parsing stopped.
What does sorting keys do?
It alphabetically orders object keys at every level, which makes two JSON documents easier to compare. Array order is never changed.
How large a file can I use?
Up to 10 million characters, though very large inputs may be slow on older phones.
